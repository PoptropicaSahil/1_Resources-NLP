# Clearing some stupid confusion

## APE (Absolute positional embeddings)

```math
\begin{align*}
PE_{(pos,2i)} &= \sin(pos/10000^{2i/d_{model}})  &= \sin(ω
_i  * pos) \\ 
PE_{(pos,2i+1)} &= \cos(pos/10000^{2i/d_{model}}) &= \cos(ω
_i  * pos) \\
ω_i &= 10000^{-2i/d_{model}} ~ \dots ~  \text{frequency}
\end{align*}
```


### 1. `pos` **`(DOWNWARDS)`**

* Position of the token in the input sequence
* **Direction:** It moves *down* the input sequence
* **Range:** $(0, \text{sequence length} - 1)$.

### 2. `i` (The Embedding Dimension Index) **`(RIGHTWARDS)`**

* Index representing a `specific pair of features inside the embedding vector of a single token`
* **Direction:** It moves *across* the embeddings of a single token
* **Range:** $(0, \frac{d}{2} - 1)$ (where $d$ is the embedding dimension, e.g., 512)
* `The positional encoding must also be a vector of size` $d$ `so it can be added to the token embedding.`

> **Why $2i$ and $2i+1$?:** The formula pairs up a sine wave and a cosine wave for every frequency. $i$ `is simply the index of that *pair*`

Example

* If $d = 512$, $i$ runs from $0$ to $255$ (which is $d/2 - 1$).
* When $i = 0$: $2i = 0$ (calculates the `0th element` using `sine`), and $2i+1 = 1$ (calculates the `1st element` using `cosine`)
* When $i = 1$: $2i = 2$ (calculates the `2nd element` using `sine`), and $2i+1 = 3$ (calculates the `3rd element` using `cosine`)
* When $i = 255$: $2i = 510$ (calculates the `510th element` using `sine`), and $2i+1 = 511$ (calculates the `511th element` using `cosine`)

> Vector of same size as $d$ is created

```math
[0, 1, 2, 3, \ldots, 510, 511] \quad (\text{embedding dimensions}) \\
( \textit{element wise addition } ) \\
[0, 1, 2, 3, \ldots, 510, 511] \quad (\text{APE dimensions}      )

```

### Visualizing the Matrix

The final Positional Encoding matrix that gets added to input embeddings - 

* The **rows** represent `pos` (different words).
* The **columns** represent the embedding dimensions ($0, 1, 2, ..., d-1$), which are generated by iterating through `i`.

|  | Col 0 ($2i$, $i=0$) | Col 1 ($2i+1$, $i=0$) | Col 2 ($2i$, $i=1$) | Col 3 ($2i+1$, $i=1$) | ... | Col 510 ($2i$, $i=255$) | Col 511 ($2i+1$, $i=255$) |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Row 0 ($pos=0$)** | $\sin(w_0 \cdot 0)$ | $\cos(w_0 \cdot 0)$ | $\sin(w_1 \cdot 0)$ | $\cos(w_1 \cdot 0)$ | ... | $\sin(w_{255} \cdot 0)$ | $\cos(w_{255} \cdot 0)$ |
| **Row 1 ($pos=1$)** | $\sin(w_0 \cdot 1)$ | $\cos(w_0 \cdot 1)$ | $\sin(w_1 \cdot 1)$ | $\cos(w_1 \cdot 1)$ | ... | $\sin(w_{255} \cdot 1)$ | $\cos(w_{255} \cdot 1)$ |
| **Row 2 ($pos=2$)** | $\sin(w_0 \cdot 2)$ | $\cos(w_0 \cdot 2)$ | $\sin(w_1 \cdot 2)$ | $\cos(w_1 \cdot 2)$ | ... | $\sin(w_{255} \cdot 2)$ | $\cos(w_{255} \cdot 2)$ |
| ... | ... | ... | ... | ... | ... | ... | ... |

### The Role of $w$ (The Frequency)

$w = 10000^{-2i/d}$.

$w$ depends *only* on $i$ and $d$, not on $pos$. Because $i$ increases as you move from left to right across the columns, the frequency of the sine and cosine waves decreases.

* `Early dimensions` (small $i$) `have very high frequencies`, meaning the sine/cosine values change rapidly as $pos$ increases. This helps the model distinguish words that are close together
* `Later dimensions` (large $i$) `have very low frequencies`, changing slowly across $pos$. This helps the model understand long-range relative positions
